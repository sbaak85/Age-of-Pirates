# B 模式與船艦操控參數

遊戲設定可切換並保存 A／B 模式，預設 A。

- A：維持左搖桿上下油門／倒船、左右船舵。
- B：左搖桿指定畫面中的航行方向；依攝影機的實際水平朝向換算世界航向。徑向死區 0.13，推動幅度決定期望航速，放開後沿用水阻與慣性減速。
- 鍵盤 W/S、A/D 維持 A 模式控制。鍵盤航行鍵按住時優先，避免與搖桿指令混合。
- B 不直接設定船頭角度或速度；沿用加速、轉舵遲滯、船體側滑、帆裝與碰撞。180 度指令會沿弧線掉頭。

## 船艦可改裝參數

目前各船狀態由 `createBoatState` 帶入以下基礎值；已留出供後續船體／舵／帆裝改裝套用的參數，尚未新增購買項目：

| 參數 | 基礎值 | 用途 |
|---|---:|---|
| `minTurnRadius` | 8 U | B 模式最小迴轉半徑，越小能轉越緊 |
| `steeringResponse` | 3.4 /s | 轉舵反應，越大越快建立或收回舵量 |
| `acceleration` | 1.32 /s | 起步與轉彎後恢復期望航速的能力 |

B 模式船頭角速度受「實際平面速度 / 最小迴轉半徑」限制，並保留原有轉向率上限；靜止時不能原地旋轉。此限制適用自由航行的船頭轉向，慣性側滑與碰撞推離仍由既有物理處理。A 模式維持原有轉向規則。

## 鏡頭設定

FOV 預設 54°（20–100），X 偏移 23（-100–100）、高度 27.2（5–100）、Z 偏移 27（-100–100），均可輸入小數並保存。距離參數使用世界 U。輸入有效值即時生效；離開欄位時超出範圍會限制到邊界，空值回復目前有效設定。
