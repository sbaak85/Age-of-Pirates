# C爆炸 — 加農砲命中預覽

入口：http://127.0.0.1:4317/game/explosion-c.html
獨立檔案：explosion-c.html、explosion-c.js、explosion-c-volume.js。
A、B 版本保留；B 保存時的 SHA256 記錄在 explosion-b-baseline.json。

設計：集中、短促的砲彈命中火光，低矮煙團，不使用大型蘑菇煙柱或空中光環。
4 個 3D 體積團塊，40 步取樣；12 個小碎片、32 道火星、局部點光源與短促衝擊環。
火焰約 0.5 秒退去，煙霧 1.5 秒消散；每 3 秒重播。
展示台與 B 版鏡頭尺度相同，便於比較大小；可用滾輪靠近觀察。
已檢查 JavaScript 語法、瀏覽器顯示與錯誤紀錄。
目前為獨立特效預覽，尚未接入遊戲命中系統，亦未量測多發同時命中的效能。
