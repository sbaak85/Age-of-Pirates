# 海戰紀元：單機可玩初版

雙擊專案根目錄的 `啟動海戰紀元.cmd`。它會在本機 `http://127.0.0.1:4317/game/` 啟動遊戲並開啟預設瀏覽器。專案已包含 Three.js 相依套件；首次使用若缺少，需安裝 Node.js 20+ 後在專案根目錄執行 `npm install`。瀏覽器需支援 WebGL 2；音效需按下「啟航」後才會播放。

## 操作

| 動作 | 鍵盤滑鼠 | 手把 |
| --- | --- | --- |
| 前進／後退、轉舵 | W/S、A/D | 左搖桿 |
| 指定左／右舷 | Q/E（暫時覆蓋自動選舷） | 右搖桿左／右 |
| 開砲 | 空白鍵或遊戲畫面滑鼠左鍵 | A |
| 張帆／收帆 | F | Y |
| 船塢／完成任務 | 靠近碼頭按 Enter | 靠近碼頭按 X |
| 暫停 | Esc | Menu |
| 選單導覽與確認 | 滑鼠、鍵盤 | 左搖桿與 A；B 返回 |

每輪側舷四門砲依序發射、間隔 0.3 秒，最後一砲後依武器填裝。沒有手動指定時，系統依最近仍存活的目標選擇左右舷；指引線只顯示船身側舷方向，玩家仍要操舵並預判砲彈飛行時間。六組目標都被擊敗且六個寶箱都回收後，回到珊瑚灣碼頭完成航程。港口船塢可修理船體與永久升級耐久、航速及砲傷害。此版本為單機遊玩循環，四人連線尚未實作。

## 出航前武器配置

啟航選單的「船艦武器配置」可分別切換左右舷砲組，每側四門同型砲。配置自動儲存在本機瀏覽器。可在暫停或結算選單返回啟航選單重新配置；再次啟航會重置當次任務，金幣及船塢升級保留。砲組仍共用一個射擊／填裝循環。

| 武器 | 單發傷害 | 彈速 | 射程 | 四發後填裝 |
| --- | ---: | ---: | ---: | ---: |
| 水手加農砲 | 22 | 21 m/s | 34.65 m | 3.2 秒 |
| 長管追獵砲 | 17 | 30 m/s | 45 m | 3.6 秒 |
| 重型破艦砲 | 34 | 15 m/s | 27 m | 4.7 秒 |

船塢砲術升級會再增加每發傷害。配置介面支援滑鼠、鍵盤方向鍵／Tab 與確認鍵，以及手把左搖桿／A；B 或 Esc 返回。

## 畫面及效能

- 海域半徑 70–96 m 漸進霧化，接近邊界有轉向提示。
- 畫質可切換平衡、高畫質、效能優先；效能優先關閉即時陰影。設定中可顯示 FPS、繪製次數及三角形數。
- 島嶼與船體合併靜態幾何，帆、砲座、魚群及可摧毀建築仍獨立活動。平衡模式降低陰影解析度並以 10 Hz 更新陰影。
- HUD 元素快取、移除每幀材質遍歷、重新出航時釋放砲彈尾跡及寶箱資源。
- 新增目標血條、命中縮放回饋、砲座後座與沉沒動畫；敵人近距離繞行並保持安全距離。
- 切到背景分頁時自動暫停與靜音，回來後由選單繼續。

邏輯測試：`node --test game/*.test.mjs`。邊界視覺檢查頁：`http://127.0.0.1:4317/game/visual-check.html`。
