# 沉眠巨獸：獨立模型預覽

開啟專案的 `/game/beast-skull-preview.html`。本模型未整合進主遊戲地圖。

## 造型與來源

依照使用者提供的五張巨大獸骨參考圖，採用長吻、洞穿的骨窗、分離張開的顎骨、雙側彎曲牙列、倒伏脊骨與叢林侵蝕。

另查閱 Smithsonian 的 [Nation's T. rex](https://naturalhistory.si.edu/explore/dinosaurs-fossils/nations-t-rex) 標本資料作為骨骼輪廓參考。本模型是原創奇幻造型，並非暴龍的科學復原；沒有使用或下載第三方掃描網格。

## 模型構造

- `tools/build-beast-skull.py`：連續體積骨殼雕塑、真實穿孔、不規則表面侵蝕，經 marching cubes 輸出索引網格。
- `cranium-*.bin` / `mandible-*.bin`：頭骨與下顎的 Float32 position/color、Uint32 index，小端序。
- `geometry.json`：網格數量與範圍，可由生成腳本重建。
- `game/beast-skull-model.js`：讀取骨殼，建立彎曲牙齒、頸椎、肋骨、貼合骨面的裂紋、植被和島地。靜態物件依材質合併，降低 draw calls。
- 風化材質以物件空間雜訊呈現斑駁、微凹凸與頂部苔蘚，旋轉時不會滑動。

遊戲執行僅需 Three.js 與本目錄內的本機資產，不需要 Python 或網路。預覽使用現有 Three.js 0.180.0；新增的 SSAO、SimplexNoise 模組沿用 `vendor/three/LICENSE` 的 MIT 授權。

## 重建

Python 3.12+，安裝 `numpy`、`scipy`、`scikit-image` 後，在專案根目錄執行：

```powershell
python tools/build-beast-skull.py
```

本次製作的 Python 套件位於 `%TEMP%/pirate-skull-meshing`，僅供建模使用，未作為遊戲相依套件。腳本也可使用一般 Python 環境中的同名套件。

目前屬於供近距離觀察的高細節版本。主地圖整合前應另製 LOD、碰撞外形及區域遮蔽設定。

## 原版 / 減面 50% 比較

另開 `/game/beast-skull-compare.html`。左側保留原版網格，右側載入 `lod50/` 的獨立減面檔。兩側使用相同材質、植被、光線與船隻，任一側的旋轉、縮放和平移均同步至另一側。

- 完整獸骨：439,614 → 219,898 三角面，實際減少約 49.98%。統計包含頭骨、下顎、68 顆牙、脊骨／肋骨及裂紋，排除植被、島地與船隻。
- 比較頁預設長、寬、高各為先前的 80%，船隻維持原尺寸。滑桿可同步調整至 60%～100%；此數值指線性尺寸，並非體積百分比。
- 原版的來源網格不變。減面檔保留頂點法線、顏色與 UV，鎖定邊界和外部尺寸極值；孔洞與分離骨骼部件經驗證保持一致。
- 載入時以來源 SHA-256 檢查相容性。修改原版骨骼後須重建減面檔，避免誤用過期的 LOD。

建模工具使用 [meshoptimizer](https://github.com/zeux/meshoptimizer/tree/master/js) 1.2.0，從官方 npm registry 取得並核對套件完整性。減面模組與 MIT 授權保留在 `tools/vendor/meshoptimizer/`，不會在遊戲啟動時下載或執行。

在已安裝專案 Three.js 相依套件的 Node.js 環境下：

```powershell
node tools/build-beast-skull-lod.mjs
node tools/verify-beast-skull-lod.mjs
```

驗證涵蓋原版資料獨立、實際三角面數、有效索引與屬性、外部尺寸、連通部件數量，以及眼窩／鼻孔／側面骨窗的穿透測試。

## 50% / 約 10,000 / 約 5,000 面三版本比較

開啟 `/game/beast-skull-compare-3.html`。目前顯示 B、C、D 三版，不再渲染 439,614 面的 A 原版；原版資產保留供離線生成與載入時來源核對。三版使用相同材質、光線、80% 線性尺寸與固定船隻比例，支援同步旋轉、縮放、平移、線框及純骨骼檢視。排版可選擇「三版並排」或「三版上下」；較窄視窗預設上下排列。

| 版本 | 完整獸骨三角面 | 相對原版減少 |
| --- | ---: | ---: |
| 50% 減面 | 219,898 | 49.98% |
| 約 10k | 9,874 | 97.75% |
| 第四版：約 5k | 4,929 | 98.88% |

10k 版依部位分配預算，沒有平均等比例壓縮每個部位：頭骨 4,846、下顎 1,500、牙齒 2,129、脊骨／肋骨 1,149、裂紋 250 面。它保留全部 68 顆牙齒與原有骨骼部件，先焊接重合的 UV 接縫頂點，再鎖定每個連通部件的尺寸極值並依曲率減面。原版及 50% 版網格保持不變。

此版本保留主輪廓、骨窗、張口與骨弓形狀；近距離觀看時，細小侵蝕和部分牙面較為簡化。頂點法線、顏色、UV 與程序式風化材質仍保留。預覽的面數統計不含三版共有的環境與船隻。

```powershell
node tools/build-beast-skull-10k.mjs
node tools/verify-beast-skull-lod.mjs --10k
```

10k 輸出位於 `lod10k/`，與 `lod50/` 分開；同樣會核對原版來源雜湊，並驗證三角面預算、所有部件、尺寸範圍及主要骨窗。

第四版由原版直接減面，前牙修正後為 4,929 面，輸出獨立的 `lod5k/`，不會覆寫其他版本。面數分配：頭骨 2,296、下顎 800、68 顆牙齒共 1,084、脊骨／肋骨 599、裂紋 150 面。沿用每個連通部件的極值鎖定、原有法線與材質，並通過部件數、尺寸、骨窗穿透與三角面預算驗證。主要輪廓保留，近距離的牙齒及細骨弧線會比 10k 版更有稜角。

```powershell
node tools/build-beast-skull-10k.mjs --5k
node tools/verify-beast-skull-lod.mjs --5k
```


## 2026-09-26 下排前牙修正

依使用者圈選，移除下排左右各兩顆最前端牙齒，共四顆（72 → 68 顆）。原始生成器保留相同亂數取樣順序，其他牙齒、骨骼、島地及植被保持不變。三個 LOD 直接刪除相同的四個牙齒連通部件並壓縮頂點索引；其餘三角面、位置、法線與顏色均原樣保留，沒有重新簡化其他部位。來源雜湊及面數已更新。

目前 B／C／D 面數分別為 219,898／9,874／4,929。以上重建工具會依最新 68 顆牙的來源重新分配減面預算，因此重建後面數可能與這次精確刪除的結果略有不同。

## 2026-09-26 寬顱、收束長吻候選版

`game/beast-skull-shape.js` 在載入基礎模型與 LOD 後，對獨立複製的網格套用可逆造型修正。X 向鼻端、Z 為寬度；眼窩附近（X = -16～-10）寬度為原本 145%，向鼻端 X = 31 以平滑曲線收回 100%，後腦連接處也平滑過渡。所有頂點的 X、Y 不變，因此長度與高度不变，三角面數也不變。

頭骨裂紋、附著於頭頂的植被／藤蔓跟隨骨面；上排每顆牙齒以完整部件平移至新的牙根位置，保持自身形狀。下排牙齒、下顎、肋骨、島地與島上植被維持原樣。原始資產不覆寫，LOD 來源雜湊仍以原網格驗證。

比較頁新增「頭頂輪廓」視角與「加寬頭型」切換，三個面板同步切換，關閉後可精確回復修改前造型。預設開啟加寬，尚未整合主遊戲地圖。

```powershell
node tools/verify-beast-skull-shape.mjs
```

驗證包含基礎版與三個 LOD 的面數、長度與高度、來源網格不變、牙齒剛性平移及反覆切換不累積變形。
