# 暮潮號：第一艘海盜船造型預覽

目前首頁預設顯示「珊瑚灣」小島。可使用底部按鈕切換到單船預覽。

- 小島：`http://127.0.0.1:4317/?view=island`
- 單船：`http://127.0.0.1:4317/?view=ship`

小島包含沙灘、三層岩台、五棟海岸建築、燈塔、階梯、棧橋、棕櫚樹、周邊島礁、水下珊瑚與魚群。`island.js` 負責島嶼幾何，海平面為 Y = 0。小島中的船縮放為 0.56，供場景比例預覽；這不是已定案的遊戲世界尺度。此版本不含島嶼碰撞或人物移動。

小島預覽另有「海浪：開／關」按鈕，可直接比較水面起伏。海浪使用三組 GPU 波形推動水面網格，港灣與岸邊的波幅較小，礁石和海岸旁有動態泡沫。暮潮號會按同一波形輕微升降和傾斜。波形資料與船身取樣在 `waves.js`，海面及泡沫材質在 `ocean.js`。目前是造型與動態預覽，未將波浪接入航行物理或砲擊規則。

採用 Three.js 0.180.0。模型使用程式建立的 3D 幾何、材質與 Canvas 船帆紋理；不依賴外部模型或遠端圖片。套件安裝完成後，預覽資源全部由本機提供。

## 啟動

在專案根目錄執行 `node preview-server.mjs`，再開啟 http://127.0.0.1:4317 。啟動腳本僅綁定本機回環位址。

## 觀看

- 初始緩慢自轉，每圈約 200 秒。
- 按住滑鼠左鍵拖曳旋轉。放開後 2.5 秒恢復自轉。
- 滾輪縮放；按鈕切換自轉、重設視角、隱藏／顯示船帆與海浪。
- 空白鍵切換自轉；方向鍵旋轉；R 重設。
- Tab 移動按鈕焦點，Enter／Space 啟動。
- 手把左搖桿選擇按鈕，A 啟動；右搖桿旋轉，LT／RT 縮放。

## 範圍

此版本是玩家船艦的造型與觀看操作預覽，尚未包含駕船、砲擊、RPG、多人連線或碰撞。

模型採 X 軸為船身縱向，+X 為船頭，Y 向上，Z 為船身左右方向。左右各四門加農砲固定朝向側舷。船帆可整組隱藏以檢視甲板；船艦主體位於 `ship.js`，場景和觀看操作位於 `main.js`。
